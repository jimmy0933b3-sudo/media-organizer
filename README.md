# 相簿整理員

Android 11 以上的離線照片／影片整理工具。無網路權限，原始檔與人臉特徵不會上傳。

## 1.8.6：一次授權免重複系統刪除確認

- Android 12（API 31）以上可在「設定 → 刪除確認設定」一次開啟系統的「媒體管理」特殊權限（`MANAGE_MEDIA`）。
- 首次按「確認刪除」且尚未授權時，App 會提供 **一次性提示**：前往系統授權，或繼續使用原本的 Android 系統確認。若略過，可從設定頁隨時重新開啟。
- 已授權時繼續呼叫 **`MediaStore.createDeleteRequest()`** 執行檔案刪除，Android 通常可以免除每批的系統確認視窗。**不是直接跳過 MediaStore 的授權機制，也不是未經確認就刪除。**
- 保留 App 自己的「確認刪除原始檔案？」警告，每次操作均須人工確認；Android 12 以上特殊權限不代表 App 可自動刪除。
- Android 11、未授權、授權被撤銷、無法開啟系統設定，都回退至 Android 既有刪除確認；單批目前最多 100 個檔案。
- `MediaStore.canManageMedia()` 每次即時檢查，僅記住是否曾顯示過一次授權提示，不儲存或假定永久授權。
- 授權不會額外提供媒體讀取權限；需要先同意照片／影片的既有存取權限，且不同廠牌 Android 可能仍有額外系統限制。
- 刪除後繼續逐項驗證媒體確實消失、掃描進行中亦可刪除；授權不足或取消不會假報成功。
- GitHub Actions 使用既有 Secrets 簽章、僅保留最新 Release。

## 1.8.5：邊掃描邊刪除

- **不需等掃描完成，即可勾選目前已顯示的照片／影片並「刪除所選」。** 仍需要在 App 和 Android 系統分別確認。
- 掃描工作繼續執行；成功的檔案才在系統授權後被逐筆核對並移出結果清單。
- 透過執行緒安全的「已刪除 URI 紀錄」，防止掃描器稍後的部分或最終結果、背景快取寫入，把已刪除的檔案重新顯示。
- 掃描器會略過已確認刪除的媒體，降低被刪照片造成的分析錯誤。
- 刪除時暫時停用再次刪除、移動、重新掃描，避免多重檔案操作。原本的掃描仍繼續；若要**移動**檔案，仍需等掃描結束。
- Android 系統授權取消、仍可讀取的媒體、查詢失敗，均不算刪除成功；不會為了維持畫面而假刪除。
- 仍僅在裝置端處理，不新增網路權限；新增並行狀態純 Java 回歸測試。

## 1.8.4：刪除確實執行與取消搜尋

- **完全移除搜尋檔名／資料夾**：主畫面的搜尋欄位、篩選邏輯和搜尋資源 ID 一併移除；四個分類與來源資料夾選擇仍保留。
- **刪除必須經過兩次確認**：在 App 確認待刪除檔案後，Android 會再顯示系統刪除授權；確認系統視窗才會實際刪除原始照片或影片。
- **不再僅因 Android 回報成功就假設刪除**：逐個向 MediaStore 核對檔案確實消失後，才更新清單並計入成功。
- **失敗與取消會明確顯示**：區分已確認刪除及未刪除／無法驗證，沒有成功的檔案不會從清單隱藏。
- **掃描期間暫停刪除／移動**：先停止或完成掃描，再執行檔案操作，避免掃描結果覆蓋刪除狀態。
- **操作被中斷可重新確認**：恢復尚未完成的刪除時，App 會再次詢問，不會擅自計算不存在或沒有讀取權限的檔案為成功。
- 原始刪除沒有 App 內回收桶；刪除前務必逐張檢查。

## 1.8.3：照片與影片雙指縮放

- **照片、影片封面及播放中的影片**均可雙指捏合放大／縮小（1×～4×）。
- 放大後可用雙指拖動畫面查看細節，不添加灰色遮罩、暗化或過場動畫。
- **移除全螢幕預覽下方的「上一張／下一張」按鈕**，留下更完整的預覽空間。
- 單指向上／下滑仍可切換下一個／上一個媒體；影片播放時單指向右快轉、向左倒退。
- 雙指操作不會誤觸媒體切換或影片快轉；切換媒體時自動還原到原始大小。
- 提供縮放比例、位移邊界的純 Java 測試；真機影片硬體畫面縮放仍須檢查。

## 1.8.2：影片左右滑動直接快轉與倒退

- **影片改用 App 內建播放器**，不再將基本播放操作交給外部 App。
- 影片播放時**向左滑直接倒退**，**向右滑直接快轉**。一般滑動約為 10 秒，滑得越長跳得越多；自動限制在影片開頭和結尾之間。
- 播放中**不加灰色遮罩、不改透明度、不套用淡入淡出特效**，直接呼叫播放器 `seekTo()`。
- 點「暫停／繼續播放」可控制播放狀態，下方顯示目前播放位置與影片總長。
- **上下滑動仍是切換上一個／下一個照片或影片**，切換時會停止前一段影片，避免背景持續播放。
- 若影片格式不受 Android 裝置支援或沒有讀取權限，畫面會明確顯示錯誤訊息。

## 1.8.1：縮圖與上下滑動預覽

- 清單縮圖不必等候完整相似度分析：當掃描產出的縮圖尚未建立、快取已遺失時，會直接從 Android MediaStore 以小尺寸讀取。
- 縮圖採背景併行載入與記憶體 LRU 快取，快速滑動清單不會讓舊縮圖錯放到新的檔案列；讀取失敗會短暫延後重試。
- 點選照片縮圖或檔名，在 App 內全螢幕預覽。**上滑下一張、下滑上一張**；v1.8.3 已移除下方切換按鈕。
- 預覽順序依目前分類，但不限於只顯示在清單前 12 張的檔案；同一媒體出現在多個群組時不重複播放。
- 影片顯示封面，按「播放這段影片」可交給手機支援的播放器。若沒有完整媒體讀取權限，部分檔案仍可能無法顯示。
- 預覽畫面在背景以適合螢幕大小的解析度載入原圖，不直接解碼相機完整解析度，減少記憶體暴增。

## 安裝與操作

1. 在手機從 [GitHub Releases](https://github.com/jimmy0933b3-sudo/media-organizer/releases/latest) 下載 `Media-Organizer.apk`，允許下載來源安裝此應用程式後安裝。
2. 點「開始掃描」，選擇授權所有照片與影片。Android 14 以上若只授權部分照片，只能分析所選檔案。
3. 保持應用程式畫面開啟直到掃描完成。可按「停止」取消；不會更動原始媒體。
4. 切換「重複／相似／人物／全部」。點縮圖或檔名，使用 App 內全螢幕預覽。
5. 填入目的資料夾名稱，如 `旅行整理`。目的地固定為手機內部儲存空間 `DCIM/旅行整理/`，照片、影片可移到同一資料夾。目的地會記住，能逐組重複移入。
6. 勾選個別檔案或整組，按「移到此資料夾」。程式確認後，Android 會再要求檔案寫入授權。
7. 要刪除時，勾選檔案並按「刪除所選」，在 App 確認後還要同意 Android 系統的刪除授權；App 會核對結果。\n8. 可使用「復原上次移動」。只保留最近一次移動操作的紀錄；跨批次仍屬同一次操作，每批最多 100 個寫入授權。

## 三種比對

- **完全重複**：同類媒體先比大小，再以完整檔案 SHA-256 核對。不同編碼或畫質不會被視為完全相同。
- **畫面相似**：照片以 64 位元 dHash、色彩、長寬比和畫面變異度比較。影片抽樣 7 個位置，至少 60% 且 3 個以上畫面符合。適合近似副本、轉檔或小幅亮度改變；不保證能找到裁切、鏡像、重剪或所有語意相似內容。
- **疑似同一人物**：Android FaceDetector 偵測清楚人臉，依眼線校正後，以 MobileFaceNet 離線產生 192 維特徵並計算餘弦相似度。每個檔案最多保留 8 個不同人臉樣本。可跨照片與影片分組；一組代表至少一張抽樣人臉接近，不代表影片中所有人都相同。

人物功能屬實驗性估計，沒有在你的相簿資料上驗證準確率；側臉、遮擋、模糊、年齡變化、多人、膚色與光線可能造成誤判或漏判。分數閾值不是準確率，也不推測人物姓名。移動前請人工預覽。

## 檔案與限制

- 只讀取 Android MediaStore 已索引且授權的手機內部儲存空間圖片／影片；不涵蓋雲端限定檔案、其他 App 私有空間、安全資料夾或所有 SD 卡搬移情境。
- 移動以 MediaStore 修改資料夾位置，不是把原始媒體複製後刪除。從外部磁碟搬到內部磁碟尚未支援。
- 同名檔案加隨機識別碼，避免覆蓋。失敗項目會計數；成功項目仍可復原。
- 復原紀錄在移動前寫入，異常中斷時可能含未移動完成的項目。復原會嘗試回到原位置；不存在或失去權限的檔案會失敗。
- 本版不自動刪除、不在背景持續監控、不自動移動新加入的檔案、不辨識人物姓名。
- 大型相簿需等待，掃描期間畫面保持亮起；離開程式後不承諾背景完成。再次掃描會重新分析，不沿用舊分組。
- 「清除縮圖快取」只清除本程式的分析縮圖；不影響你的原始媒體與復原紀錄。移除 App 會清除復原紀錄。

## 開發建置

使用 Android Studio 匯入此資料夾，JDK 17、Gradle 8.9、Android SDK 35，AGP 8.7.3。執行 `gradle :app:assembleDebug` 會產生可安裝 Debug APK。第一次需下載 Gradle／Android SDK／TensorFlow Lite 相依套件。本 ZIP 未包含 Gradle wrapper 或 Android SDK。

GitHub Actions 發布的 Release APK 使用 Actions Secrets 提供的簽章金鑰，不會再使用公開的本地測試憑證 `signing/local-testing.p12`（該憑證仍用於本地 Debug）。若新金鑰與舊版 APK 不同，無法直接覆蓋更新，卸載舊版會失去本機快取與復原紀錄。請參閱 [BUILD-APK.md](BUILD-APK.md) 的必要 Secrets、簽章相容性及 CI Release 保留規則。
